# Contributing to Rules4Agents

Thank you for your interest in contributing to Rules4Agents! Before submitting your contribution, please read this document carefully.

## How to Contribute

1. Fork this repository.
2. Create a new branch for your changes.
3. Make your changes and commit them with clear, descriptive messages.
4. Submit a Pull Request describing the purpose and content of your changes.

## Contribution Guidelines

- Contributions should align with the project's scope: rules designed to regulate and enhance agent behavior, covering areas such as tool calling, deep reasoning, and more.
- Please follow the existing file naming conventions and formatting style.
- If you are adding a new rule, provide both English and Chinese versions.
- Include clear descriptions and rationale for any new rules or modifications.
