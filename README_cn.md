# Tool Calling Rules

## 项目介绍

本项目定义了一套约束大语言模型（LLM）调用外部工具的规则。这些规则旨在减少 LLM 在工具调用过程中常见的参数格式错误、工具选择不当、错误恢复低效等问题，从而提升工具调用的准确率和效率。

项目包含以下文件：

| 文件 | 说明 |
|------|------|
| `toolCallingRulesV0.md` | 初始版本规则（英文） |
| `toolCallingRulesV0CN.md` | 初始版本规则（中文翻译） |
| `toolCallingRulesV1.md` | 优化后的 V1 版本规则（英文） |
| `toolCallingRulesV1CN.md` | 优化后的 V1 版本规则（中文） |
| `README.md` | 项目说明文档（英文） |
| `README_cn.md` | 项目说明文档（中文） |
| `LICENSE` | AGPL-3.0 许可证文件 |

## V1 优化理由

V1 版本在 V0 的基础上进行了系统性优化，具体如下：

### 1. 新增"调用前准备"类别

V0 缺少调用前的约束，导致 LLM 经常在未充分理解工具描述的情况下盲目调用，或凭空捏造参数值。V1 新增了三条规则：

- **先读后调**：强制要求在调用前完整阅读工具描述和参数说明，避免基于工具名称猜测行为。
- **禁止捏造参数值**：对于不确定的参数值，要求先通过查询获取真实值，杜绝 LLM 常见的"幻觉"问题。
- **确认必填与可选**：明确区分必填和可选参数，减少因参数遗漏或冗余导致的调用失败。

### 2. 新增枚举值精确匹配规则

V0 未涉及枚举类型参数的约束。LLM 常在枚举参数中传入大小写或拼写不匹配的值。V1 新增规则要求枚举值必须与描述中列出的允许值完全一致。

### 3. 路径规则增强

V0 仅要求路径不添加格式修饰，但未明确要求使用绝对路径。在实际使用中，相对路径常因工作目录不同而解析失败。V1 新增"使用绝对路径"规则，除非工具描述明确允许相对路径。

### 4. 关联参数规则扩展

V0 仅提到成对参数须同时提供，但未涉及参数间的条件依赖关系（如参数 A 仅在参数 B 取特定值时生效）。V1 新增了条件依赖关系的规则，避免传入无效参数组合。

### 5. 新增"工具选择与调用策略"类别

V0 仅有一条工具选择规则，且未涉及并行/串行调用策略。V1 扩展为三条规则：

- **优先使用最具体的工具**：继承 V0 规则并强化表述。
- **独立调用可并行**：明确允许无依赖的调用并行发起，减少交互轮次。
- **有依赖时须串行**：明确要求有数据依赖的调用必须串行，禁止猜测返回值。

### 6. 错误恢复规则增强

V0 有两条错误恢复规则，V1 新增一条：

- **遇到权限或不存在错误时停止重试**：V0 未覆盖此类场景，LLM 常在遇到 "file not found" 或 "permission denied" 后盲目重试相同调用。V1 要求先确认路径或权限，必要时使用查询工具核实。

### 7. 新增"安全与副作用"类别

V0 完全未涉及安全相关规则，这是重大遗漏。V1 新增三条规则：

- **破坏性操作须谨慎**：对删除、覆盖等不可逆操作要求确认。
- **避免冗余修改**：先读取再判断，避免无意义的覆盖写入。
- **尊重幂等性**：区分幂等与非幂等操作，防止重复调用导致数据重复或状态错误。

### 8. 结构优化

V0 的规则采用扁平编号（1-10），分类较粗。V1 重新组织为七大类别，每类下规则独立编号，结构更清晰、更易于 LLM 理解和遵循：

| V0 分类 | V1 分类 |
|---------|---------|
| 参数格式 | 调用前准备（新增） |
| 参数格式 | 参数格式 |
| 路径和标识符 | 路径与标识符 |
| 关联参数 | 关联参数 |
| 错误恢复 | 工具选择与调用策略（新增） |
| 错误恢复 | 错误恢复 |
| 工具选择 | 安全与副作用（新增） |

### 9. 示例与格式增强

V1 在关键规则处增加了代码示例和对比表格，使规则更直观、更易于 LLM 准确理解。
